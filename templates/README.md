# templates/

Formato oficial de MAKYL que la aplicación replica:

- **Rendición de Gastos** (hoja carta, logo, tabla FECHA · DOCUMENTO · Descripción · Nuevos Soles · Dólares).
- **Planilla de Movilidad Diaria** (hoja A4, una por día).

Si existe el Excel original de la empresa, va en esta carpeta (`*.xlsx` en `templates/` sí se versiona).
No guardar aquí comprobantes ni rendiciones llenas.
